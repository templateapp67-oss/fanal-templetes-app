# Environment setup

Run `npm run setup:env` to create a git-ignored `.env`. Existing files are never
overwritten. No dependencies are needed for this command. It creates two independent
32-byte random secrets and leaves provider-issued credentials blank. A generated
file is a setup draft, not a working production configuration.

| Screenshot variable | What to enter |
| --- | --- |
| `VITE_GOOGLE_MAPS_API_KEY` | Not used by this revision. Maps directions use ordinary Google Maps links. Omit this variable. |
| `SUPABASE_DEMO_OWNER_ID` | Optional fallback: an existing salon owner's Auth user UUID, not an API key or a new random UUID. Prefer resolving the owner through the published salon. |
| `DEFAULT_OWNER_ID` | Preferred fallback alias; takes precedence over `SUPABASE_DEMO_OWNER_ID`. Leave both blank unless a fallback owner is intended. |
| `YOUTUBE_API_KEY` | Your Google Cloud API key with YouTube Data API v3 enabled; needed for automatic video/channel fetching. |
| `YOUTUBE_DATA_API_KEY` | Legacy fallback alias. Leave blank when `YOUTUBE_API_KEY` is set. |
| `VITE_SUPABASE_FUNCTIONS_URL` | Not read by the current frontend. Omit it. If implementing direct Edge Function calls later, use your project's base URL. |
| `RAZORPAY_MOCK_MODE` | `false` disables simulated payments; real online payment requires the Razorpay API key pair. Use `true` only for an intentional simulation. |
| `RAZORPAY_MOCK_SECRET` | Generated by the setup command; only used for simulated payments. |
| `RAZORPAY_WEBHOOK_SECRET` | Generated by the setup command. Enter the same value in your Razorpay webhook configuration for `/api/payments/razorpay/webhook`. It is separate from your Razorpay API secret. Do not replace an existing webhook secret on only one side. |
| `DB_TIMEOUT_MS` | `6000` |
| `DB_LOOKUP_TIMEOUT_MS` | `4000` |
| `API_REQUEST_TIMEOUT_MS` | `9000` |

## Account values still required

- Set `VITE_SUPABASE_URL` and `SUPABASE_URL` to the same Supabase project URL.
- Set `VITE_SUPABASE_ANON_KEY` and `SUPABASE_ANON_KEY` to that project's public key.
- Set `SUPABASE_SERVICE_ROLE_KEY` only on the server for booking persistence.
- Set `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` from the same Razorpay test/live key pair if accepting online payment.
- Set `APP_URL` to your actual app URL. Configure `GEMINI_API_KEY` if using AI features.
- Set the YouTube key above if using automatic YouTube fetching.

Enter values in the hosting provider's environment/secrets settings, not GitHub
source files. Do not put server secrets in variables beginning with `VITE_`.
When entering a dashboard value, omit the `.env` surrounding quotes. Rebuild the
frontend after changing `VITE_` values and restart/redeploy the backend after
changing server values. GitHub repository secrets alone do not configure a host
unless a deployment workflow explicitly passes them through.

## Verification after account setup

Check `/api/health`, then `/api/health?deep=1` for database readiness. Run
`npm run verify:connection` for the existing database verifier. The existing
`npm run check:razorpay` command can create a small provider order, so use test
credentials for that check. Confirm a test webhook is accepted before live use.

Provider references: [YouTube API setup](https://developers.google.com/youtube/v3/getting-started),
[Supabase API keys](https://supabase.com/docs/guides/api/api-keys),
[Razorpay webhooks](https://razorpay.com/docs/webhooks/setup-edit-payments/).
